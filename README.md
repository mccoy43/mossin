# MOSSIN Laundry City - Premium Laundry Website

A modern, premium laundry service website built with Next.js, React, Tailwind CSS, and Framer Motion.

## 🎨 Features

- **Luxury Dark Theme** - Black/dark navy background with gold (#D4AF37) and deep blue (#0A3D62) accents
- **Responsive Design** - Fully mobile-responsive layout
- **Smooth Animations** - Framer Motion animations and transitions
- **High-Quality Images** - Gallery section with premium imagery
- **Comprehensive Sections**:
  - Hero section with animated particles
  - Services showcase
  - How It Works step-by-step guide
  - Gallery with hover effects
  - Pricing plans
  - Testimonials
  - Contact & booking form
  - Footer with social links

## 🚀 Getting Started

### Prerequisites
- Node.js 16.x or higher
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser
